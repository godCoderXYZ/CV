    % In the video, I showcase and present my project, flowchart architecture, and program implementation. This project, PassPersona, was created for the PolyU Hatch Awards Competition, the 6th greater bay area STEM competition, and the Hong Kong Science Fair Competition. The purpose of PassPersona is to manage passwords for elderly users. We chose this demographic because elderly users are more prone to memory loss and isolation. PassPersona acts as a friendly companion, providing assistance and helping elderly people manage their passwords so that they don’t have to.
    % We eliminate the need for memorizing passwords through voice recognition and speech diarization, which is implemented through the AssemblyAI API, where the user’s voice acts as their unique master password. Moreover, the openAI API is used for its LLM capabilities, allowing elderly users to have personalized conversations with PassPersona. We also implement text-to-speech and speech recognition to incorporate a hands-free interface, removing the need for keyboard-based input from elderly users and increasing usability and accessibility. The project uses Python for the frontend and backend, and SQL for database management through the psycopg2 python module. Security is handled through hashing and encryption algorithms using the Crypto, base64, and zlib python modules, while techniques such as salting and hashing are implemented through a key derivation function handled by the PBKDF2 module.
